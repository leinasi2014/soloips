# 重构文档入口

**用户裁决（2026-09-15）：当前开发、修复和验收一切以重构文档为准；旧文档只作参考。**

## 优先级与使用规则

1. 用户最新明确要求优先，并由统筹同步更新受影响正文及原生任务。
2. 本目录已确认需求与定稿设计决定重构实现和验收；同题内容以正文收敛后的规则为准。显式建议、待决项不因文档整理自动变为已批准需求。
3. 目录外重构前产品、架构、协议、UI 和路线文档仅作历史或源码侦察参考；其中“唯一权威”“必须”“兼容”等措辞不对新重构产生要求。旧 prompt 和旧测试也不能反过来修改重构要求。
4. 官方接口事实、当前访问权限、数据保护和仓库工程命令仍按实际环境及现行工程规则核对；它们不授权降低重构产品要求。

## 统筹必须完成的文档维护

- 发现冲突时更正唯一正文，旧位置留下迁移链接；不得用“旧文档要求”继续开发已取消的兼容或可选入职路径。
- 每个任务指向本目录具体需求 ID；工作分支文档过时就使用本入口指定的当前正文，并在候选中同步文档变更。
- 阅读优先级不等于实现进度。逐项核对生产代码、测试反例、集成包和实际运行行为；缺少任何一层都标明缺口。
- 原生任务保留负责人、状态与证据；本目录不另建滚动状态台账。
