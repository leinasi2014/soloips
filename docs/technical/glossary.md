# 技术术语

> 技术架构 §3。SoloIPs 项目的核心术语定义。

## 交付相关

| 术语 | 定义 |
|---|---|
| 插件包 | DSH 能力交付单元；SoloIPs = 一组插件包 + 一个 profile |
| bundle | `dsh.profile.bundles` 的条目，决定 patch 层叠加顺序 |
| profile | 声明 bundles 数组与部署设置的 DSH 装配清单 |
| 装配 | DSH 组合配置并按服务依赖激活插件的过程 |
| 组合 | 一次交付所选插件包 + profile + 版本锁定的静态清单 |

## 状态相关

| 术语 | 定义 |
|---|---|
| domain | DSH 持久化的命名状态域 |
| 写权威 | 某类事实的唯一合法写入来源 |
| 投影 | 由权威事实派生的只读视图 |

## 配置相关

| 术语 | 定义 |
|---|---|
| patch | 按 id 定位行后替换给出的顶层字段 |
| 行 id | 配置行的稳定定位标识 |
| append | dsh plugin add 只追加，不改既有行 |

## 状态相关

| 术语 | 定义 |
|---|---|
| revision | 乐观锁版本号，用于 CAS 操作 |
| operationId | 命令的稳定标识，贯穿提交、结果和恢复 |
| fence | 跨进程写保护机制 |

## 失败相关

| 术语 | 定义 |
|---|---|
| 单包失败 | 特定 bundle 解析/挂载失败，不等于整体失败 |
| 停线 | 某链路出错时停止受影响的后续动作 |
| 恢复 | 从检查点重新开始的能力 |

## 验收相关

| 术语 | 定义 |
|---|---|
| 验收基线 | 验收结论绑定的指名版本组合 |
| 冷启动 | 从完全停止状态启动 |
| 热重载 | patchReload: live 下的运行时更新 |
