## 0. 为什么需要这份清单

版本级预研（Skill §8.5）产出的**版本接口蓝图**若只存在于会话里，下一个功能就会各写各的接口，导致返工。本清单把「蓝图与相关文档是否齐备」变成**开工前的可核对条件**。

**两条纪律**：

1. **文档齐备是开工条件，不是收尾工作。** 缺蓝图就开工 = 各功能独立设计接口 = 必然返工（这正是版本级预研要解决的问题）。
2. **动态状态不入提交正文**（`agent-readable-documentation.md` §7；`project-binding.yaml` 的 `liveStatusInCommittedMarkdown: forbidden`）。「谁在做、卡在哪、哪个版本可用」留在原生任务系统与本机记录。
