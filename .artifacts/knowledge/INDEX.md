# SoloIPs 知识包索引（效率制度 v2）

> 性质：派生知识导航层——帮新实例免重复侦察，**不是权威**。涉实际修改/关键判定/矛盾时必须回权威原文（data-contract / 设计文档 / 源码）。
> 元数据要求：每包标〔性质｜来源版本(commit)｜稳定 ID｜适用范围｜验证状态｜失效条件〕。否定性结论标高风险。
> 维护：变更者提出更新 → 指挥审核 → 不可变版本化发布（v1/v2…），本索引指向最新。
