# SoloIPs 知识包索引

> 性质：派生知识导航层——帮新实例免重复侦察，**不是权威**。涉实际修改/关键判定/矛盾时必须回权威原文（data-contract / 设计文档 / 源码）。
> 元数据要求：每包标〔性质｜来源版本(commit)｜稳定 ID｜适用范围｜验证状态｜失效条件〕。否定性结论标高风险。
> 维护：**稳定路径 + Git 历史 + 工单固定 commit 引用**（不再另造 v1/v2 文件家族）；变更者提出更新 → 指挥审核。

## 启动索引（新实例先读这份，替代重读 1700 行契约）

**默认启动材料只需三样**：本索引 → 该任务档案 → 本任务涉及的权威条款与源码入口。
按需加载：`test-env.md` 只在需要跑测试时读；`commander-system-review.md` 只给指挥与外审读，**不是写手启动必读**；已完成切片的侦察档案不再出现在默认启动面。

| 包 | 路径 | 内容 | 失效条件 |
|---|---|---|---|
| 代码库地图 | `codebase-map.md` | 包职责/风格范式/关键文件入口/构建与五门跑法 | 大重构或包结构变化 |
| BE-4 任务档案 | `be4-recon.md` | BE-4a/4c 落点（方法/函数稳定 ID）+ 缺口表 | BE-4 交付后缺口表失效，降为历史 |
| 测试环境 | `test-env.md` | 测试跑法/沙箱结构/日志规范/样板路径 | 测试工具链或目录约定变化 |
| 体系复盘 | `commander-system-review.md` | #34 问题史与重规划来源 | 仅供指挥/外审 |

> **任务状态只在 Issue/检查点；实现状态由源码支撑 data-contract §0；测试结果只来自报告/CI。本索引只链接，不复制这三类状态。**
